# Плотина

Залипательная головоломка про воду: направляй цветные потоки через трубы к резервуарам,
пока вода не размыла землю под ними. Сделана под мобильный экран и Telegram Mini Apps.

## Как играть

Сверху — три источника цветной воды, снизу — три резервуара с заказами (цветной кружок —
какую воду они принимают за полную цену). Вода течёт вниз сама: по голой земле — только
прямо вниз, боком — только через трубы. Непокрытая трубой клетка, по которой стоит вода,
размывается; когда земля рушится, вода утекает в провал и поднимает уровень паводка.
Паводок на 100% = конец игры.

- **Тап по клетке** — поставить трубу из очереди (одна установка за короткий кулдаун —
  вода не ждёт). **Тап по трубе** — повернуть. **Двойной тап** — убрать.
- Труба-разветвитель (Т) делит поток; смешение двух цветов в одной клетке даёт
  **грязную воду** — она истирает трубы, в которых течёт, и стоит дешевле.
- **Не тот цвет резервуара** — вода переливается: резервуар примет треть, остальное
  утечёт и поднимет паводок. Со 2 по 4 уровень заказы меняются по одному —
  прямые каналы придётся перестраивать.
- **Золотая труба** удваивает очки; камень полностью блокирует поток.
- Подряд доставки без протечек растят **комбо-множитель** (до ×8). Протечка сбивает его.
- Заполненный резервуар — бонус и новый заказ. С уровнями вода течёт быстрее
  (до разумного предела) и открываются новые цвета.

### Управление (клавиатура)

WASD/стрелки — курсор, Пробел/Enter — поставить, R — повернуть трубу в очереди,
Q — обменять первые две трубы, X — убрать трубу, Esc/P — пауза, M — звук.

## Запуск

```bash
npm install
npm run build        # dist/ — статический сайт
node scripts/verify-game.mjs   # самопроверка (скриншоты + консоль + маппинг клавиш)
```

## Технологии

- Canvas2D рендер: кэшированный статичный слой (плитки/трубы) + динамический слой
  (вода с волновыми поверхностями, бегущие блики в трубах, частицы) — без аллокаций
  в кадре, пулы частиц, деградация качества при просадке FPS.
- Фиксированный шаг симуляции (60 Гц), поток воды — дискретные тики с обратным давлением.
- Web Audio: весь звук синтезирован в рантайме (вода, камень, фанфары), адаптивный
  шум воды по объёму воды на поле, моношireнг через первый жест.
- Telegram Mini Apps: haptic feedback, expand/disableVerticalSwipes — только если скрипт
  Telegram уже есть в webview, в обычном браузере всё отключается.
- localStorage: рекорд, статистика, настройка звука (локально в браузере, между
  устройствами не синхронизируется).

## Структура

- `src/game/board.ts` — симуляция: поток, эрозия, резервуары, комбо, уровни
- `src/game/renderer.ts` — отрисовка и раскладка
- `src/game/game.ts` — состояния, ввод, события → juice
- `src/game/pieces.ts` — трубы и очередь; `particles.ts` — пулы частиц
- `src/game/audio.ts` — синтез SFX; `telegram.ts` — опциональная интеграция
